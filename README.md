# GlowNest Case Study — Viability & Profitability Analysis

Business analysis case study for a D2C brand concept (**GlowNest**): market viability, unit-economics model, and MD-ready talking points.

> This repository is a **case-study pack** (Excel + Word docs). For the cleaner, formula-driven Excel model built for portfolio use, see also: [`d2c-profitability-model`](https://github.com/sarthakraj2506-hash/d2c-profitability-model).

## What’s inside
| File | Purpose |
|---|---|
| `GlowNest_Profitability_Model.xlsx` | Profitability / unit-economics workbook |
| `GlowNest_Viability_Analysis.docx` | Viability analysis write-up |
| `GlowNest_MD_Talking_Points.docx` | Status update + leadership talking points |
| `GlowNest_Discovery_Notes.docx` | Discovery notes / sketches |

## Business focus
- Is the concept viable under Base / optimistic / downside assumptions?
- What are contribution margin, break-even, and marketing efficiency watch-outs?
- What should leadership decide next (pricing, CAC, assortment, channel mix)?
